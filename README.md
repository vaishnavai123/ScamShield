# 🛡️ ScamShield – Scam Message Detection System

## 📌 Project Overview

ScamShield is a web-based scam message detection system developed using Python and Flask. It helps users identify potentially fraudulent or suspicious messages by analyzing their content and assigning a risk level.

The main objective of this project is to create awareness about online scams and help users recognize suspicious messages before responding to them.

## ✨ Features

- **Message Analysis:** Users can enter a message for analysis.
- **Scam Detection:** Identifies suspicious words and patterns using rule-based analysis.
- **Risk Assessment:** Assigns a risk level such as Low, Medium, or High.
- **User-Friendly Interface:** Simple and easy-to-use web interface.
- **Instant Results:** Displays the analysis result after submitting a message.

## 🛠️ Technologies Used

- Flask
- HTML

## ⚙️ Installation and Setup

Follow these steps to run the project on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/vaishnavai123/ScamShield.git
```

**2. Open the project folder**

```bash
cd ScamShield
```

**3. Install the required libraries**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python app.py
```

**5. Open in your browser**

```text
http://127.0.0.1:5000/
```
